Python-песочница

Настоящий Python 3.12 прямо в браузере: вся стандартная библиотека, f-строки, json, re, dataclasses, asyncio. Код работает в отдельном потоке, так что даже бесконечный цикл не повесит страницу — через 15 секунд он остановится сам.

Задачи с автопроверкой

Маленькие функции из жизни DevOps-инженера: разобрать лог, конфиг, вывод df. Напиши функцию и нажми «Проверить» — тесты покажут, где расхождение. За каждую решённую задачу +25 XP. Код сохраняется сам.

Свободный редактор

При первом запуске браузер скачает Python (~10 МБ), дальше он берётся из кеша. Сторонние пакеты (requests, fastapi), сеть, потоки и input() здесь недоступны — такие примеры запускай у себя. В уроках 2.1–2.5 у примеров есть кнопка «▶ выполнить».
